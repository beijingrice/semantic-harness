# 泛化评测协议（v0.3.0 起）

这份协议要回答一个问题：**这个检查器在没见过的文本上表现如何。** 旧数据集都在调试中反复用过，不能回答这个问题（见 [project_analysis.md](../project_analysis.md) 4.2 节）。

## 两份新数据集

| 文件 | 条数 | 用途 | 谁可以看 |
|---|---:|---|---|
| `examples/validation_v030_gen_dev_60.json` | 60（30 PASS / 30 FAIL） | 开发集：分析错误、改进代码 | 任何人 |
| `examples/validation_v030_blind_99.json` | 99（50 PASS / 49 FAIL） | 盲测集：只用来报告成绩 | 只看汇总指标，不看样例内容 |

两份数据的分布相同：12 个类别，约 30% 是多段落长文本；PASS 和 FAIL 的中英文长度比几乎一样，不能靠"中文变短了"来猜答案。

## 怎么生成的

1. **从零编写，与项目隔离。** 两份数据分别由一个独立的 Codex 实例（gpt-6.2-sol，high）在空目录中编写。它看不到本仓库的代码、旧数据集和历史报告，用的说明就是本目录下的 [generation_brief.md](generation_brief.md)（实际运行时 `__N__`、`__PREFIX__` 两个占位符没有替换成功，所以 ID 是事后统一改写的，数量由生成者自行决定）。
2. **避开待定的标注问题。** 生成说明要求不出现 [labeling_guidelines.md](../labeling_guidelines.md) 中 4 个待定现象：should、描述句对规范句、充分条件对必要条件、范围有争议的近义词。所以这两份数据的标签不依赖尚未定下来的规则。
3. **独立复核标签。** 另一个看不到原标签的实例（gpt-6-luna，high）按 [relabel_brief.md](relabel_brief.md) 重新标注。结果：开发集 60/60 一致；盲测集 100 条中 1 条不一致，已剔除，剩 99 条。
4. **跨模型抽查。** Claude 抽查了开发集的 20 条，全部同意。盲测集没有抽查，以免看过内容。

## 跨模型挑战集

`examples/validation_v030_challenge_claude_32.json`（16 PASS / 16 FAIL）由 Claude 编写，用来检查同家族偏差（上面两份都是 GPT 写、GPT 复核），并刻意加大难度：大幅改写的 PASS，以及只有一处细微差异的 FAIL，例如数量范围、否定范围、例外挂到了另一个对象上、工作日对自然日、日期边界开闭、二选一对两者都要、跨段落指代等。gpt-6-luna 在看不到标签的情况下独立复核，对 2 条提出异议（"by 9:00"对"9点前"、"by 10 May"对"5月10日前"在边界是否包含当天上有歧义）。我同意这是编写失误，改写了中文措辞（改成"最迟于"）。CH-13/CH-31 的英文也从 "the group that submits later" 改成 "the group with the later deadline"，因为评测中复核模型指出前者也可以理解为"实际较晚提交的那组"。

注意：第一次运行时，CH-08 暴露了数值守卫的 bug（"不小于"被解析成"<"），代码已据此修复。所以这份挑战集**不是盲测集**，只能作为难度更高的补充测量。

## 盲测集的使用规则

- **只在两个时间点运行**：改动开始前的基线，以及一轮改动全部完成后的最终评估。每次运行都记入下面的运行记录。
- **只看汇总指标**：端到端正确率、转人工率、误判率、按类别统计。不读具体样例，也不按单个盲测样例的失败去改代码或提示词。
- **改代码只看开发集和旧数据集**。给 Codex 的任务说明里要写明不得读取 `validation_v030_blind_99.json`。
- 文件冻结，`validation_v030_blind_99.sha256` 记录校验值，`tests/test_eval_datasets_v030.py` 检查它没有被改动。一旦盲测集被用于调试，必须在这里和 [DATASETS.md](../../examples/DATASETS.md) 中注明，并另建新的盲测集。

## 已知局限

- **合成数据**：样例是模型写的，不是真实的课程或机构文件。语言自然度经过抽查，但分布和真实文档肯定不同。
- **同家族模型**：编写和复核都是 GPT 系列，可能有共同的盲点；被测系统也可以用 GPT 模型运行，这时存在"同家族偏好"的可能。
- **规模有限**：99 条的 95% 置信区间大约是 ±8 个百分点，只适合发现明显差异。
- **不覆盖待定现象**：这两份数据说明不了 should 等 4 类问题上的表现。
